# Бот — карта части

**Что это:** рабочий Telegram-бот. Отвечает своим людям, чужих не пускает.

**С чего запускается:** `main.py`. На Railway работает круглосуточно, у себя второй раз не запускать.

**Главные файлы:** `main.py` — бот; `test_bot.py` — проверка без Telegram; `requirements.txt` — библиотеки.

**Данные:** свои файлы бот не хранит: на Railway они пропадают при новой выкладке.

**Поток:** сообщение в Telegram → пропуск по номеру → обработчик → ответ или файл.

**Где живёт и откуда берёт ключи:** Railway, настройки `TELEGRAM_BOT_TOKEN` и `TELEGRAM_SVOI`.
