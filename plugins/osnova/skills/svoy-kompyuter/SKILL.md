# Маршрут «свой компьютер»

Полный текст этого навыка — на сервере метода. Сразу, до любого ответа или вопроса человеку, вызови
инструмент `poluchit_navyk` (сервер `znaniya`) с именем `svoy-kompyuter` и дальше действуй строго по полученному тексту.
Если текста навыка в разговоре уже не видно (например, после сжатия разговора) — получи его заново тем же инструментом.
