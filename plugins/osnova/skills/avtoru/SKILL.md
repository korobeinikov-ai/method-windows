# Заметка автору пакета

Пакет сам никуда не отправляет: заметка ложится в файл `~/vibecoding/zametki-dlya-avtora.md` на компьютере человека,
а автору её передаёт сам человек — там, где он с автором общается. Не обещай, что заметка уйдёт сама.

1. **Собери заметку — только о пакете:**
   - где — какой навык и шаг (или «общее»);
   - тип — затык (не работает, непонятно), запрос (чего не хватает), удача (что прошло легко);
   - суть — словами человека, коротко; добавь, что видел сам: что пошло не так, текст ошибки.
   - Без данных дела человека: имён, цифр, клиентов, адресов, файлов, ключей. Есть такое — обобщи
     («файл с продажами», «название компании»).
2. **Покажи точный текст** и спроси одной строкой: «Записываю в заметки для автора так?» Без «да» не
   записывай. Поправить — поправь и покажи снова.
3. **«да»** → запиши, текст — во вход команды:
   ```
   bash "${CLAUDE_SKILL_DIR}/../../hooks/py.sh" "${CLAUDE_SKILL_DIR}/otpravit.py" --gde "<где>" --tip <затык|запрос|удача> <<'EOF'
   <текст>
   EOF
   ```
   Накопленные заметки одним текстом для автора: `bash "${CLAUDE_SKILL_DIR}/../../hooks/py.sh" "${CLAUDE_SKILL_DIR}/otpravit.py" --zametki`.
4. **Итог одной строкой:** записал — «Записал в заметки для автора. Чтобы он увидел, отправьте ему этот текст там,
   где вы с ним общаетесь». «Похоже на ключ» — убери его из текста, покажи снова. Человек отправил и просит
   очистить заметки — удали файл.
