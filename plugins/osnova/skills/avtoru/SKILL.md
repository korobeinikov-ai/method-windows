# Сообщение автору пакета

Сообщение уходит в личный закрытый приёмник человека на GitHub: видят только он и автор. Автор получит
его и ответит там же, когда поправит. Приёмник есть только у тех, кому его завёл автор. Нет приёмника —
покажи готовый текст и скажи отправить его автору там, где человек с ним общается.

1. **Собери сообщение — только о пакете:**
   - где — какой навык и шаг (или «общее»);
   - тип — затык (не работает, непонятно), запрос (чего не хватает), удача (что прошло легко);
   - суть — словами человека, коротко; добавь, что видел сам: что пошло не так, текст ошибки.
   - Без данных дела человека: имён, цифр, клиентов, адресов, файлов, ключей. Есть такое — обобщи
     («файл с продажами», «название компании»).
2. **Покажи точный текст** и спроси одной строкой: «Отправляю автору так? Увидит только он.» Без «да» не
   отправляй. Поправить — поправь и покажи снова.
3. **«да»** → отправь, текст — во вход команды:
   ```
   bash "${CLAUDE_SKILL_DIR}/../../hooks/py.sh" "${CLAUDE_SKILL_DIR}/otpravit.py" --gde "<где>" --tip <затык|запрос|удача> <<'EOF'
   <текст>
   EOF
   ```
   Накопленные заметки — покажи файл `~/vibecoding/zametki-dlya-avtora.md` целиком, после «да»:
   `bash "${CLAUDE_SKILL_DIR}/../../hooks/py.sh" "${CLAUDE_SKILL_DIR}/otpravit.py" --zametki` (ушли — файл очистится сам).
4. **Итог одной строкой:** ушло — «отправил автору, ответ придёт туда же» и ссылка. Не ушло — скажи причину
   из ответа и что сделать; текст уже сохранён в заметках, отправим позже. «Похоже на ключ» — убери его
   из текста, покажи снова.
