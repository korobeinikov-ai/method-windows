## Правила
- **Деньги — только после «да»:** публикация рекламы, бюджеты, продвижение постов. Всё новое — черновиком.
- **Пароли и коды — владелец.** Ты их не вводишь и не просишь в чат.
- **В Chrome (если он есть) — только загрузка файла в медиатеку и просмотр.** Включать, публиковать, менять бюджеты, оплату, роли
  и настройки в интерфейсе Meta нельзя, даже если коннектор не справился, — тогда скажи владельцу. Своя вкладка: чужие вкладки
  не трогай, из аккаунтов не выходи, настройки безопасности не меняй.
- **Вопросы — по одному**, с вариантами и твоей рекомендацией первой. Не спрашивай то, что видно в кабинете.
- **Чужие кампании** (прошлого таргетолога, владельца) — только смотреть; менять — после «да».

## Шаг 2. Коннектор Meta — 3–5 минут
0. **Команда Claude Code.** `command -v claude`. Нет её (человек пользуется только приложением Claude) — найди ту, что внутри
   приложения: её путь обычно в переменной `CLAUDE_CODE_EXECPATH`; пусто — найди самую новую программу Claude Code в папке
   данных приложения Claude (папка `claude-code`).
   Найденный путь во всех командах ниже (и во вкладке терминала, пункт 3) пиши вместо `claude` целиком, в кавычках:
   `"<путь>" mcp get meta-ads`. Переменную не заводи — между командами она теряется. Путь не нашёлся — к пункту 2,
   «Не вышло ни так, ни так».
1. **Есть ли он уже.** `claude mcp get meta-ads`.
   - Есть и подключён — к пункту 4. Есть, но просит вход — к пункту 3.
   - Есть с областью «user» (виден во всех папках) — допиши те же правила ещё и в `~/.claude/settings.json`, ничего чужого не удаляя:
     иначе в другой папке реклама включится без вопроса.
   - Инструменты Meta (`ads_get_ad_accounts` и соседние) у тебя есть под другим именем — например, коннектор из claude.ai
     (`mcp__claude_ai_<имя>__…`) — пользуйся им, а в правилах замени `mcp__meta-ads` на его начало имени (во всех трёх разделах).
2. **Добавить** (только для этой папки проекта — так правила подтверждений его точно покрывают):
   ```
   claude mcp add --transport http meta-ads https://mcp.facebook.com/ads
   ```
   Своё приложение Meta и ключ доступа обычно не нужны — вход через Facebook.
   **Не вышло ни так, ни так** (нет ни `claude`, ни копии в приложении) — положи в корень проекта `.mcp.json`:
   `{"mcpServers": {"meta-ads": {"type": "http", "url": "https://mcp.facebook.com/ads"}}}` (уже есть — допиши сервер, чужое не
   удаляя). ✋ Такой сервер Claude Code включает только после одобрения человека: попроси владельца открыть новый чат в этой папке,
   согласиться подключить `meta-ads` и войти через `/mcp`.
3. **Войти:** `claude mcp login meta-ads`. Команде нужен живой терминал — из обычного запуска команд она падает со словами «stdin isn't
   a terminal». Есть у тебя инструмент, который запускает команду во вкладке терминала владельца (в приложении Claude — панель
   Terminal), — запусти там: откроется окно Meta в браузере, а терминал напишет «Authenticated», когда вход пройдёт. Нет такого
   инструмента — попроси владельца набрать `/mcp`, выбрать `meta-ads` и «Authenticate».
   ✋ Владелец входит в Facebook, выбирает бизнес и рекламные кабинеты, к которым даёт доступ, и нажимает «Продолжить».
   Своё приложение Meta для этого не нужно. Если вход всё же падает с ошибкой клиента или приложения — скажи владельцу прямо;
   запасной путь (ещё ~10 минут): в Chrome на developers.facebook.com/apps создай приложение со сценарием «Create & manage ads with
   ads MCP server», затем `claude mcp remove meta-ads` и
   `claude mcp add --transport http --client-id <номер приложения> meta-ads https://mcp.facebook.com/ads`, снова вход.
4. **Инструменты появились?** После входа через `/mcp` — обычно сразу. После входа из терминала уже открытый чат его не видит:
   ✋ попроси владельца набрать `/mcp`, выбрать `meta-ads` и «Reconnect» (входить заново не придётся). Не помогло — запиши в
   `target/JOURNAL.md`, на каком ты шаге, и попроси владельца открыть новый чат в этой же папке (в приложении Claude — вкладка
   Code, новый чат, та же папка; в терминале — `claude -c`) с фразой
   «продолжай первое подключение таргетолога».
5. **Проверка:** `ads_get_ad_accounts` показывает кабинеты владельца. У каждого смотри: `is_ads_mcp_enabled` (false — Meta ещё не
   включила коннектор для этого кабинета, причина в `is_ads_mcp_disabled_reason`; такой кабинет не трогай), `is_queryable`,
