
## Это Windows
Команды — только через Git Bash: охрана видит только их, PowerShell и cmd в обход не используй. Тексты навыков с сервера
общие с Mac — по-маковски написанное делай так:
- Python: `python3` здесь часто пустышка — команда из строки «Команда Python здесь» ниже. Среда проекта: `.venv/Scripts/python.exe` и `.venv/Scripts/pip.exe`.
- Показать человеку папку или файл (на Mac — `open`): `explorer "$(cygpath -aw <путь>)"` (код ответа 1 — не ошибка).
- Человеку: Ctrl вместо Cmd, «Пуск» вместо Finder. Работает он в приложении Claude, вкладка Code.
- Вместо `Обновить.command`: `Обновить.bat` — `@echo off`, `cd /d "%~dp0"`, `.venv\Scripts\python.exe …`, при ошибке `pause`.
- Пути из `${…}` могут прийти с `\` — в командах пиши `/`.
- Ключи — только через `klyuch.py` (`pbpaste` здесь нет): он берёт буфер обмена и закрывает `.env` от других пользователей. Его предупреждение про историю буфера (Win+V) передай человеку.
- Файлы пакета не правь: обновление их сотрёт. Скрипт не работает — правь его копию в папке проекта. Охрану не ослабляй.
