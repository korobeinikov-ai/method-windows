# Карта: метод KOROBEINIKOV AI для Windows

**Что это.** Версия метода для Windows 10 и 11: основа — снимок от 11.11.2026 (метка `vypusk-2026-11-11-1155`), вход
через приложение Claude — с 13.11.2026. Людям пакет раздаёт склад метода на домене (с 25.11): каталог
`https://metod.korobeinikov.ai/windows/marketplace.json`, пакеты — zip-архивами по sha256, инструкция и установщик —
`/windows/CLAUDE.md`, `/windows/install.ps1`. Склад собирает выпуск мастерской из этой папки (сохранённое, ветка `domen`)
и заголовков навыков Mac, кладёт на сервер тем же сохранением, что и Mac-склад. Репо на GitHub
(korobeinikov-ai/method-windows) пакет новым людям больше не раздаёт: его `main` заморожен для подключённых по старой
схеме. Механика (установка, охрана, проводник, скрипты) заморожена: меняется только по слову автора «обнови Windows».

## Как ставится у человека
Приложение Claude → вкладка Code → фраза из `README.md` (или личный текст из бота метода) → Claude читает `CLAUDE.md` →
сам запускает `install.ps1` с домена одной командой в фоне (видит `CLAUDE_CODE_EXECPATH`: Claude не ставит и не запускает) — Git,
Python (winget для пользователя; нет winget или не справился — установщики с сайтов программ, версии и суммы закреплены,
без окна «Разрешить»), настройки охраны (переменные пользователя и `settings.json`), полка `korobeinikov-ai-windows` со склада
на домене (git для самого пакета не нужен), пакеты `osnova` и `stroka`, программы пакета, автообновление с того же каталога,
личная ссылка из `METHOD_DOSTUP` (на домене или прежняя, `…/u/<ссылка>?os=windows`:
PowerShell-скрипт с сервера кладёт ключ в `~/.config/korobeinikov-ai/klyuch`, папка закрыта `icacls`), проверка охраны,
пути проводника. Пока она идёт, Claude в том же чате знакомится и спрашивает название дела; потом «да» на настройки,
проект скриптами проводника с диска (через Git Bash и `py.sh`) → итог по строке: что сделала установка и что даёт метод
(15.11) → один новый сеанс сразу в папке проекта (решение 14.11).
Ошибки подготовки изнутри Claude адресованы Claude («почини и запусти снова»), человеку команд не показывают.
Охрана в новом сеансе не видит Git или Python — проводник просит один раз полностью закрыть Claude и открыть снова.
Мак-фраза (`https://metod.korobeinikov.ai/CLAUDE.md`) на Windows тоже ведёт сюда: её инструкция отправляет Claude к
`https://metod.korobeinikov.ai/windows/CLAUDE.md`.

## Главные файлы
- `README.md` — страница для людей: три шага установки. `CLAUDE.md` — инструкция Claude, если человек просит поставить метод.
- `install.ps1` — подготовка с чистой машины (Windows PowerShell 5.1 и 7); повторный запуск ничего не меняет.
  Без Claude (обычное окно PowerShell) ставит и запускает Claude сам.
- `.claude-plugin/marketplace.json` — полка `korobeinikov-ai-windows`: `osnova` и `stroka`. На складе выпуск делает из неё
  каталог на архивы.
- `plugins/osnova/hooks/` — охрана: `block-env-commit.py` (.env не в git), `verify-gate.py` («готово = доказано»),
  `verify-evidence.py`, `lint-after-edit.py`, `gitfind.py` (git только по полному пути), `py.sh` (настоящий Python),
  `session-start.sh` (правила и состояние человека в каждый сеанс), `hooks.json`.
- `plugins/osnova/.mcp.json`, `znaniya/znaniya.py` — посыльный: полный текст навыка с сервера по личному ключу. Запуск —
  Git Bash + `py.sh -I -X utf8`; команды Mac в тексте (`python3`, `.venv/bin`) переводит на Windows.
- `plugins/osnova/rules/` — `PRAVILA.md`, `WINDOWS.md` (как делать по-маковски написанное). `plugins/osnova/skelet/` — заготовка проекта.
- `plugins/osnova/skills/` — `start` (проводник, `instrumenty.sh`, `nastroyki.json`) и `avtoru` — полные, под Windows.
  `start/baza.sh` (21.11) — подготовка зовёт его после пакета: убирает из личных инструкций Claude блок «Базовый метод»,
  который кладут наборы автора (только между метками `korobeinikov-ai-baza`, копия рядом, CRLF сохраняется).
  `avtoru` (с 15.11): заметка через посыльного (`zametka`) на сервер метода по личному ключу → автору в Telegram.
  `railway`, `telegram-bot`, `baza`, `bezopasnost`, `premortem`, `svoy-kompyuter`, `systematic-debugging` — заголовки (их кладёт выпуск
  мастерской), рядом свои скрипты под Windows: `railway/klyuch.py` (ключи через буфер обмена и stdin), шаблон бота на aiogram.
- `plugins/stroka/` — строка над полем ввода в приложении: копия Mac-версии, от системы не зависит.
- `tests/` — `test-hooks.sh`, `test-klyuchi.sh`, `test-provodnik.sh`, `test-shablon.sh`, `test-teksty.sh`, `test-znaniya.sh`,
  `test-ustanovka.ps1`; `sklad.py` — склад метода на машине проверки (сборка из этой папки, HTTPS с адресами домена).

## Как проверять
Главная мерка — прогон на настоящей Windows: `.github/workflows/windows.yml` (windows-latest) идёт на каждый push.
Установка с чистой машины без Git и Python, повтор «изнутри Claude» (как в приложении), `claude plugin validate`,
`claude mcp list` (посыльный виден), инструменты пакета, все `tests/` в строгом режиме (нет gitleaks, ruff или node —
провал), поиск значений ключей в журналах. Условие «готово» — зелёный прогон на ветке `domen` (с неё собирается склад).
Быструю проверку логики можно сделать на Mac (`bash tests/test-hooks.sh` и другие), но она Windows не заменяет.
Обычный прогон — путь новичка по складу: `tests/sklad.py` собирает склад из этого коммита и отдаёт по HTTPS на самой
машине, домен `metod.korobeinikov.ai` ведёт туда записью в hosts (сертификат свой, доверенный только там). Установщик —
`irm …/windows/install.ps1 | iex`, пакеты Claude Code берёт архивами и сверяет sha256 (неверная sha — отказ),
настройки автообновления — на каталог домена. Кнопка `s_domena` (Run workflow) — то же против настоящего склада на
домене: её запускать после выпуска. Окно приложения Claude прогон не видит.
Личная ссылка для Windows проверяется настоящим PowerShell в репо сервера (`korobeinikov-ai/server`, свой прогон на Windows).

## Как обновлять
Механику — только по слову автора «обнови Windows»: нужное переносится из мастерской вручную, имена полки и пакетов остаются
`korobeinikov-ai-windows`, `osnova`, `stroka`, потом зелёный прогон. Заголовки навыков `vypusk.sh` мастерской кладёт
при сборке склада сам (новый навык — целиком), сюда их не возит. Мастерская поменяла, как навык зовёт свои скрипты, —
это тоже «обнови Windows»: скрипты здесь свои. Рабочая ветка — `domen` (из неё собирается склад, выпуск требует, чтобы
она была сохранена и отправлена); `main` заморожен: по нему ещё обновляются подключённые по старой схеме.

## Правила
Никакого бизнеса автора, значений ключей и абсолютных путей чужих компьютеров в файлах. Тексты для человека —
простым русским. Только Windows 10/11 и стек автора (приложение Claude, Git, Python, GitHub, Railway, Supabase, Telegram).
