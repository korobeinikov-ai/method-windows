# Метод KOROBEINIKOV AI для Windows

Метод для предпринимателей: Claude ведёт вас от «хочу» до работающей вещи и сам делает всю технику.
Вы думаете о деле и процессах, а от вас нужны только руки: подтвердить вход и нажать кнопку там, где Claude скажет.

Сайт: https://korobeinikov.ai. На Mac метод ставится такой же фразой, но со ссылкой на инструкцию для Mac:
https://raw.githubusercontent.com/korobeinikov-ai/method/main/CLAUDE.md

> **Claude, тебя попросили поставить метод на Windows?** Инструкция для тебя — [CLAUDE.md](CLAUDE.md), целиком:
> `irm https://raw.githubusercontent.com/korobeinikov-ai/method-windows/main/CLAUDE.md`. Сначала расскажи человеку,
> что поставишь, и дождись его «да».

## Для кого
Для предпринимателей, которые не программируют: хватит уровня ChatGPT и Excel. Нужны компьютер с Windows 10
(версия 1809 и новее) или Windows 11 и платная подписка Claude (Pro или выше). Права администратора обычно не нужны.

## Как поставить
1. **Поставьте приложение Claude** со страницы https://claude.ai/download: откройте скачанный файл и пройдите
   установку (Windows спросит разрешение — нажмите «Да»). Запустите Claude из меню «Пуск» и войдите своей подпиской.
   Компьютер на процессоре Snapdragon (ARM) — берите
   [эту ссылку](https://claude.ai/api/desktop/win32/arm64/setup/latest/redirect). У большинства обычный процессор.
2. **Откройте раздел Code** (переключатель вверху окна). Под полем ввода выберите папку «Документы».
3. **Вставьте в поле ввода текст и нажмите Enter:**

```
Поставь метод Коробейникова с https://github.com/korobeinikov-ai/method-windows — прочитай целиком инструкцию для тебя https://raw.githubusercontent.com/korobeinikov-ai/method-windows/main/CLAUDE.md и коротко расскажи, что поставишь. После моего «да» ставь.
```

Дальше Claude ведёт сам. От вас — несколько кнопок и ответов:
- Claude расскажет, что поставит, — ответьте «да».
- Claude спрашивает разрешение — нажмите «Разрешить».
- Windows может спросить «Разрешить этому приложению вносить изменения?» — нажмите «Да».
- Claude спросит, как называется ваше дело, и можно ли поставить настройки как у автора.
- В конце нажмите кнопку под сообщением Claude: откроется ваш проект, и можно начинать работу.

Установка обычно занимает до получаса, почти всё это время идёт скачивание.

Уже ставили метод раньше? Переставлять ничего не нужно: метод обновится сам. В разделе Code откройте папку своего
проекта (она лежит в папке vibecoding в вашей домашней папке) и работайте как обычно.

## Что поставится и безопасность
Весь код открыт здесь, установщик — [install.ps1](install.ps1). Хотите проверить сами — попросите Claude прочитать его
и объяснить до установки.

Установка ставит:
- Git и Python для вашего пользователя: через winget или с сайтов программ, контрольные суммы закреплены; только если
  оба способа не сработали, Windows спросит разрешение на изменения;
- настройки, с которыми Claude работает через Git Bash, где стоит охрана ключей;
- сам пакет — штатной установкой плагинов Claude Code;
- три программы с их официальных страниц на GitHub — связь с GitHub (gh), сканер паролей (gitleaks), проверка кода
  (ruff); в вашу домашнюю папку, версии и контрольные суммы закреплены;
- автообновление пакета и папку vibecoding для проектов.

Только с вашего «да»: настройки Claude как у автора (копия прежних сохраняется) и уборка правил прежнего набора автора
из личных инструкций Claude, если они там есть.

Пакет не просит пароль и не отправляет ваши файлы, разговоры и данные ни автору, ни на чужие серверы. Копия вашего
проекта — только в ваш собственный закрытый GitHub, когда вы его подключите.

## Что внутри
- Правила работы: Claude говорит просто, делает технику сам и ведёт одним проверенным путём.
- Охрана: ключи и пароли не попадают в сохранения, «готово» — только после проверки, судья смотрит на готовую работу.
- Опыт автора: свой компьютер (таблицы и файлы), Telegram-бот, выкладка в интернет, база данных, таргетолог для рекламы
  в Instagram и Facebook, цифровая безопасность, поиск причины поломки, разбор рисков перед большим делом.

Всё это лежит в самом пакете, общее с версией для Mac, и обновляется само.

## Вопросы
Пакет даётся как есть: за свой проект отвечаете вы. Пишите автору там, где вы с ним общаетесь.
