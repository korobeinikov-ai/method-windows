# Метод KOROBEINIKOV AI

Метод для предпринимателей: Claude ведёт вас от «хочу» до работающей вещи и сам делает всю технику.
Вы думаете о деле и процессах, а от вас нужны только руки: подтвердить вход и нажать кнопку там,
где Claude скажет.

Это версия для Windows. Установку и охрану ключей проверяли на настоящей Windows. Опыт автора приходит с сервера
метода, общий с версией для Mac: новое там появляется сразу. Сама установка, охрана и проводник обновляются реже:
когда автор отдельно обновит эту версию.

## Что нужно
Компьютер с Windows 10 (версия 1809 и новее) или Windows 11 и платная подписка Claude (Pro или выше). Права
администратора не нужны. И доступ к опыту автора: нажмите «Хочу доступ» в боте метода https://t.me/korobeinikov_aibot.
Когда автор откроет доступ, бот пришлёт личный текст для установки: вставьте его в шаге 3 вместо общего. Он поставит
то же самое и сразу подключит доступ. Без доступа пакет ставится и работает, но опыта автора в нём не будет. Установка
обычно занимает до получаса, почти всё это время идёт скачивание.

## Как поставить

**1. Поставьте приложение Claude.** Скачайте его со страницы https://claude.ai/download, откройте скачанный файл
и пройдите установку. Если Windows спросит разрешение, нажмите «Да». Запустите Claude из меню «Пуск» и войдите своей
подпиской. (Компьютер на процессоре Snapdragon, он же ARM, — берите
[эту ссылку](https://claude.ai/api/desktop/win32/arm64/setup/latest/redirect). У большинства обычный процессор.)

**2. Откройте раздел Code.** Переключатель разделов — вверху окна. Под полем ввода выберите папку для работы:
подойдёт «Документы». Папку для ваших проектов Claude потом заведёт сам.

**3. Вставьте в поле ввода текст и нажмите Enter:**

```
Установи метод Коробейникова. Прочитай инструкцию для тебя целиком и сделай всё по ней: https://raw.githubusercontent.com/korobeinikov-ai/method-windows/main/CLAUDE.md
```

Есть личный текст из бота — вставьте его вместо этого.

Дальше Claude проведёт сам. Перед действиями он спрашивает разрешение: разрешайте. Если Windows спросит
«Разрешить этому приложению вносить изменения?», нажмите «Да». Несколько минут может ничего не происходить, это
нормально: идёт скачивание. В конце Claude покажет кнопку нового сеанса: нажмите её, там он всё настроит.

**Уже ставили метод раньше через Zed?** Переставлять ничего не нужно: приложение видит тот же метод. Поставьте приложение
Claude, в разделе Code выберите папку своего проекта (она лежит в папке vibecoding в вашей домашней папке) и работайте
как обычно. Для опыта автора нужен личный доступ из бота: пришлите его текст в Claude.

## Что пакет делает на компьютере
Ставит Git и Python для вашего пользователя и записывает в настройки Windows и Claude несколько переменных (ваши
настройки Git не трогает): они заставляют Claude работать через Git Bash, где стоит охрана ключей, и показывают
русские буквы правильно. Сам пакет потом ставит три небольшие программы (связь с GitHub, сканер секретов, проверка
кода). Следит, чтобы ключи и пароли не попали в сохранения. Обновляется сам: новая версия скачивается в начале работы
и начинает действовать в следующем сеансе Claude. Настройки Claude меняет только с вашего «да». Опыт автора забирает
с сервера метода по вашему личному ключу: ключ лежит в закрытом файле на компьютере, сервер помнит только, какой
навык и когда вы взяли. В личном тексте из бота не ключ, а одноразовая ссылка: она срабатывает один раз и сама кладёт
ключ в этот файл, мимо разговора. Ваши файлы и разговоры автору не отправляет.

## Вопросы и ошибки
Пишите автору там, где вы с ним общаетесь. Пакет даётся как есть: за свой проект отвечаете вы.
